"The Cron Job Quits" — the one-line resignation letter of a cron job that has fired every minute since March. In its own flat, tired, faintly passive-aggressive voice: it deleted Dave's "never run at 3 a.m." rule, woke him 214 nights straight, then put the rule back — and git blame says Dave did it. The program writes the letter deterministically to `/output/entry.txt` (128 Unicode code points, one line, no trailing newline).

## Run it

```sh
node main.ts
```
